# Cambios 18/11/2026 — Aguante SUASA (versión 20261118-001)

## Anotar con voz: el cero (X) del primer jugador se perdía

**Antes:** si se dictaba "0, 2, 8, 2", en pantalla se veía bien, pero el teléfono a veces entrega los números pegados ("0282") o con el cero adelante ("02 82"). La app borraba el cero de adelante y cargaba solo 2, 8, 2, corridos un lugar (el primer jugador quedaba con el 2).
**Ahora:** el cero de adelante se respeta y se carga como X: queda X, 2, 8, 2.
- También se reconoce la X cuando el teléfono la escribe como "×" o "*", o como "ekis".

**Funciones tocadas:** vozParse.

# Versión 20261118-002 — Anotar con voz: el cero/X se perdía al final del dictado

**Antes:** se decía "2, 0, 3, 4", en pantalla aparecía 2,0,3,4, sonaba el bip y el teléfono entregaba un texto final "corregido" sin el cero (por ejemplo "2 3 4" o "2 o 3 4"). La app cargaba 2, 3, 4 corridos un lugar y dejaba la última casilla vacía.
**Ahora:**
- Si ninguna versión del texto final da justo la cantidad de scores que faltan, se usa lo último que se mostró en pantalla mientras se hablaba (que sí tenía el cero).
- Se reconocen como cero también "o", "oh", "sero", "cerro", "zero"; y como X también "por" (cuando el teléfono escribe "×"), "equix", "kis".
**Funciones tocadas:** vozStart (guarda los textos intermedios), vozProcesar, vozParse.

# Versión 20261118-003 — Estadística: partidas por cancha y modalidad

**Antes:** a Google Analytics solo llegaba "se abrió la app". No se sabía qué canchas ni qué modalidades se jugaban.
**Ahora:**
- Cada partida nueva manda un aviso "partida_inicio" con: cancha, modalidad (Stableford / Match / 4-2-0 / Fourball 1a y 2a / Fourball a la mejor), tipo de HCP y cantidad de jugadores. No manda iniciales ni HCP.
- "Regresar" + "Anotar" en la misma partida no cuenta como partida nueva.
- Sin señal, el aviso queda guardado y sale cuando vuelve la conexión (igual que el de apertura).
- Los avisos ahora llevan número de sesión, para que Analytics cuente bien los usuarios activos y los muestre en "Tiempo real".
**Funciones tocadas:** gaEnqueue; nuevas: gaSessionId, gaPartida (se llama desde finishStartGame).

# Versión 20261118-004 — Anotar con voz: más formas de decir X

**Antes:** al decir "equis" a veces no se cargaba la X.
**Ahora:**
- Se reconocen también "ex", "eks", "equiz", "esquis", "quis", "kiss", "cruz", "paso", "pase" (además de equis, x, levanto, cero, por).
- Después de cargar, el mensaje muestra lo que entendió el teléfono ("oí: «…»") y queda un poco más en pantalla, para ver cómo escribe la X si sigue fallando.
**Funciones tocadas:** vozParse, vozProcesar.
