# Cambios 19/11/2026 — Aguante SUASA (versión 20261119-001)

## Anotar con voz: "X X" daba "No entendí XX"

**Antes:** al dictar dos X seguidas, el teléfono las escribía pegadas ("XX") y la app no lo reconocía.
**Ahora:** las X pegadas entre sí o a un número se separan: "XX" → X, X; "4XX5" → 4, X, X, 5.
**Funciones tocadas:** vozParse.

# Versión 20261119-002 — Anotar con voz: varias X seguidas

**Antes:** al dictar 4 X el teléfono escribió «x**» y se cargaron solo 3.
**Ahora:** si ninguna versión del texto da justo la cantidad de scores, se usa la que trae más (incluidas las que se fueron mostrando mientras se hablaba).
- Para varias X seguidas conviene decir "cero" o "levanto": el teléfono las escribe como números y se cargan bien.
**Funciones tocadas:** vozProcesar.

# Versión 20261119-003 — Estadística: celulares con la app instalada

**Antes:** el número que identifica a cada celular (sin saber de quién es) se podía borrar solo, sobre todo en iPhone, y ese celular contaba como nuevo. No se sabía si la app se abría instalada o desde el navegador.
**Ahora:**
- Al abrir, la app le pide al teléfono que no borre sus datos (sin cartel). Si lo acepta, el número del celular y la partida guardada no se borran solos.
- Cada aviso a Analytics dice "instalada: si/no" según se abra desde el ícono de inicio o desde el navegador.
**Funciones tocadas:** gaEnqueue; nuevas: gaInstalada, pedido de guardado permanente al cargar.
